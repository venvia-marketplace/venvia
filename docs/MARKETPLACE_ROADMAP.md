# Marketplace VenVia — roadmap iniziale

Il Marketplace sarà un modulo proprietario di VenVia, non un gestionale distinto.

1. Portare Negozio Zero all'autonomia operativa; completare contratti API Core.
2. Stabilizzare Store Connector, catalogo, magazzino, vendita e integrazioni web.
3. Definire contratti API multi-negozio e prove di isolamento.
4. Attivare il Marketplace solo con approvazione e collaudi completi.

La rete condivide un catalogo, mentre giacenze, costi, clienti e documenti rimangono separati secondo la proprietà dei negozi. La struttura definitiva del modulo dipende dalla verifica del Core esistente.
